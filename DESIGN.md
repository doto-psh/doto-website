# doto Design System

## Direction

doto uses a cobalt-blue operating-desk identity: precise, clear, and tool-like. The interface should feel like a useful workspace rather than an editorial brochure.

## Tokens

- Primary blue: `#135dff`
- Primary blue strong: `#003fc7`
- Ink: `#101827`
- Muted text: `#637085`
- Background: `#f7f9fd`
- Surface: `#ffffff`
- Blue surface: `#edf4ff`
- Line: `#d9e2ee`
- Supporting accents: cyan `#16a7c8`, lime `#9bbf24`, coral `#ff6b4a`

## Typography

- Primary font: `Inter Variable`
- Headings: heavy sans, no negative letter spacing
- Body: medium-weight, scan-friendly line height

## Shape And Layout

- Card radius: max `8px`
- Use visible borders and grid structure before shadows
- Prefer full-width bands and constrained inner content
- Product visuals should look like template dashboards, not abstract gradients
- Avoid soft blobs, ocean waves, pill-heavy controls, and warm editorial serif styling

## Interaction

- Clickable elements must look clickable without hover
- Primary actions use solid cobalt
- Secondary actions use bordered white surfaces
- Motion stays small: translate, color, and subtle scale only
